# Use a two-field terminal frame and pre-decrement its counter

Cleanup emits cached width and limb count above the unchanged bounded suffix. The guard reads exponent size from the real header. Its hit and exponent-three stub push k-1, and the terminal copies that counter while preserving the generic tail index contracts.

Full local run: **355,367 gas**, **44/44 vectors**, **10,994 bytes**, independent Lean default kernel accepted. Runtime SHA-256: `6ca2f67cacf949bbe38a5e655cc82eceb2da0583cca6fcacf94d4fecdc471e0d`.
